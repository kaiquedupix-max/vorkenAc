SEM COMPLICAÇÃO

Perguntas comuns.
Respostas claras.

O que é o Vorken Scanner?

É uma plataforma de verificação para comunidades de Rust. O scanner organiza sinais técnicos do computador em um relatório para revisão administrativa, com bot Discord e plugin conectados ao painel.

Preciso configurar IP ou RCON?

Não. Você cadastra o servidor, adiciona o bot ao Discord e baixa o plugin vinculado ao seu cadastro. A comunicação do plugin com o painel acontece por HTTPS.

Minha equipe também pode acessar?

Sim. No painel do servidor, use Equipe e convites para convidar seus administradores. Cada equipe acessa somente os servidores para os quais recebeu autorização.

Um alerta de outro servidor aplica um banimento?

Não. O alerta informa o servidor de origem e o motivo. Sua equipe decide se deseja verificar, liberar, ignorar ou aplicar uma ação local.

Quem decide se o jogador será banido?

A administração revisa as evidências e toma a decisão. As regras de recusa, desconexão e prazo são configuradas pelo responsável pelo servidor.
