Como funciona o Vorken Scanner

O Vorken Anti-Cheat conecta o servidor Rust, o Discord e o painel de administração.

1

Solicite a verificação

A equipe inicia a telagem pelo bot Discord ou pelo painel. O jogador recebe o código e o prazo no Rust.

2

Entre no ticket privado

O jogador envia o código no canal de verificação e recebe um link exclusivo para abrir o scanner.

3

Revise as evidências

O relatório organiza ocorrências críticas, itens para revisão, histórico suspeito e inventário. A administração avalia o contexto e seleciona as provas.

4

Decida no painel

A equipe libera ou bane o jogador. O painel aguarda a confirmação da ação pelo plugin no Rust e registra a auditoria.

Banimentos anteriores na rede podem gerar alertas para a equipe de outro servidor quando o jogador conectar. Um alerta não aplica um novo banimento automaticamente.
