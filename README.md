# Vorken Anti Cheat

O **Vorken Anti Cheat** é um scanner forense para Windows desenvolvido para auxiliar administradores de servidores na análise de possíveis trapaças.

O funcionamento é simples: o jogador executa o Vorken, autoriza a análise e o programa coleta evidências técnicas do Windows relacionadas a execução de programas, dispositivos USB, histórico do sistema, arquivos, navegador, integridade de processos e outros artefatos relevantes. Depois, essas informações são enviadas para o painel administrativo, onde podem ser revisadas antes de qualquer decisão.

O Vorken não foi desenvolvido para coletar senhas, cookies, mensagens privadas, fotos ou documentos pessoais.

## Aviso sobre antivírus e VirusTotal

Por realizar verificações profundas no Windows, consultar diversos artefatos do sistema e utilizar técnicas comuns em ferramentas forenses, o executável do Vorken pode eventualmente ser identificado por alguns antivírus ou pelo **VirusTotal** como suspeito.

Essas detecções podem ser **falsos positivos** e não significam, por si só, que o programa contenha vírus ou malware.

Sempre utilize o Vorken distribuído pelos canais oficiais e, quando disponível, confira o hash SHA-256 e a assinatura digital do executável.
